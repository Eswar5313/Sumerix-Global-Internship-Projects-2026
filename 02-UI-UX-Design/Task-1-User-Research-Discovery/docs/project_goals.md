# Project goals & success metrics

| Type | Goal | Metric |
|---|---|---|
| User goal | Complete a handover in ≤ 5 min (median) | Timed in usability test & app analytics |
| User goal | Incoming lead knows every open item before the first truck | ≥ 95% critical items acknowledged within 15 min |
| Business goal | Fewer missed pending loads / SLA breaches caused by handover gaps | −50% handover-related misses in 8-week pilot |
| Business goal | Auditable safety communication | 100% of safety flags carry owner + acknowledgement |
| Product goal | Adoption by floor leads | ≥ 80% of shifts in the pilot hub use ShiftLoop by week 4 |
| Experience goal | Trust in received information | Trust score (Q9) from ≤ 2.5 → ≥ 4.0 on a 5-point scale |
