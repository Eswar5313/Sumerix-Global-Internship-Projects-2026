# Part A & B — UI vs UX, Design Thinking

**UI** = visual & interactive layer (layout, colour, type, components). **UX** = how well the whole journey achieves the user's goal.
**Product design** adds business viability; **service design** spans every channel of the service.

| App | UI example | UX example |
|---|---|---|
| WhatsApp | Bubbles, ticks, mic button | Read receipts remove uncertainty; works on 2G |
| Amazon | Product cards, sticky Buy Now | One-click reorder, live tracking |
| Spotify | Dark theme, album art | Offline downloads |

## Design Thinking on the handover problem
Empathize (observe 3 handovers) → Define (personas, problem statement) → Ideate (crazy-8s, card sort) → Prototype (wireframes → hi-fi) → Test (timed handover with 5 leads).
